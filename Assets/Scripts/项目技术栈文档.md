# MyNetGameProject 技术栈文档

> 最后更新时间: 2026-04-01
> 维护者: 项目开发团队

---

## 一、项目概述

这是一个基于 Unity 的多人在线射击游戏项目，采用客户端-服务端架构，使用 UDP 协议进行网络通信。

---

## 二、技术栈详解

### 1. 游戏引擎

| 技术 | 版本/说明 |
|------|----------|
| Unity | Unity 6.x (使用新 API 如 `rigidbody.linearVelocity`) |
| Input System | 新版输入系统 (`UnityEngine.InputSystem`) |
| TextMeshPro | UI 文本渲染 |

### 2. 网络架构

| 组件 | 说明 |
|------|------|
| **协议** | UDP (`SocketType.Dgram`, `ProtocolType.Udp`) |
| **端口** | 服务端监听 9050 端口 |
| **网络库** | 自研 DJRNetLib |
| **通信模式** | 客户端-服务端 (C/S 架构) |
| **数据序列化** | BinaryWriter/BinaryReader 二进制序列化 |

### 3. 数据包系统

```
PacketType 枚举:
├── None = 0
├── Join = 1              // 玩家加入
├── PositionAndStatus = 2 // 位置和状态同步
├── Move = 3              // 移动指令
├── Attack = 4            // 攻击指令
└── ScenesItem = 5        // 场景物品同步
```

### 5. 设计模式

| 模式 | 应用位置 |
|------|----------|
| **单例模式** | `SingelBase<T>` 基类，用于 GameRoot, Server, NetworkPlayerManager |
| **事件驱动** | `Action` 委托用于事件回调 (玩家加入、死亡、消息接收等) |
| **组件模式** | Unity 组件化设计，功能拆分为独立组件 |
| **生产者-消费者** | `ConcurrentQueue` 用于跨线程消息队列 |

### 6. 游戏系统

| 系统 | 说明 |
|------|------|
| **玩家系统** | 移动、攻击、相机跟随、面向鼠标 |
| **怪物系统** | 波次生成、追踪玩家、难度递增 |
| **战斗系统** | 子弹发射、碰撞检测、伤害计算 |
| **生命值系统** | HPBase 基类，玩家/怪物继承 |
| **同步系统** | 位置、旋转、状态实时同步 |

## 三、可能导致游戏报错的代码

### 严重问题 (高优先级)

#### 问题 1: HPBase.cs 伤害计算逻辑错误

**文件位置:** `Server/conmon/HP/HPBase.cs` 第 16-18 行

**问题代码:**
```csharp
public void TakeDamage(float damage)
{
    if(CurrentHealth>=damage) CurrentHealth-= damage;
    else IsDead.Invoke();  // 问题1: 没有减去伤害
                           // 问题2: IsDead 可能为 null
}
```

**问题分析:**
- 当 `CurrentHealth < damage` 时，没有正确扣减血量，直接触发死亡
- `IsDead` 事件没有订阅者时会抛出 `NullReferenceException`

**修复建议:**
```csharp
public void TakeDamage(float damage)
{
    CurrentHealth -= damage;
    if (CurrentHealth <= 0)
    {
        CurrentHealth = 0;
        IsDead?.Invoke();
    }
}
```

#### 问题 2: PlayerInstance.cs OnDisable 字典访问异常

**文件位置:** `Server/Player/PlayerInstance.cs` 第 118-124 行

**问题代码:**
```csharp
private void OnDisable()
{
    UserPositionAndStatusPacket userStatusPacket = 
        Server.Instance.serverAllPlayerManager.AllPlayerInstancesUserPositionPackets[PlayerIp];
    // 如果 PlayerIp 不存在于字典中，会抛出 KeyNotFoundException
    Server.Instance.serverAllPlayerManager.AllPlayerInstance.Remove(PlayerIp);
    // ...
}
```

**问题分析:**
- 直接使用索引器访问字典，如果键不存在会崩溃
- `Server.Instance` 可能为 null

**修复建议:**
```csharp
private void OnDisable()
{
    if (Server.Instance?.serverAllPlayerManager == null) return;
    
    var manager = Server.Instance.serverAllPlayerManager;
    
    if (manager.AllPlayerInstancesUserPositionPackets.TryGetValue(PlayerIp, out var userStatusPacket))
    {
        manager.AllPlayerInstance.Remove(PlayerIp);
        manager.AllPlayerInstancesUserPositionPackets.Remove(PlayerIp);
        userStatusPacket.isDead = true;
        Server.Instance.serviceUpdate.SendToAllPlayerDestoryOBJ(PacketType.PositionAndStatus, userStatusPacket);
    }
}
```

}

#### 问题 4: MonsterBase.cs 空列表访问

**文件位置:** `Shared/SceneObject/SceneMonster/MonsterBase.cs` 第 57-62 行

**问题代码:**
```csharp
public void FindPlayerMinDistance()
{
    PlayerInstance targetInstance = Playerlist[0];  // 如果列表为空，IndexOutOfRangeException
    // ...
}
```

**修复建议:**
```csharp
public void FindPlayerMinDistance()
{
    if (Playerlist == null || Playerlist.Count == 0) return;
    
    PlayerInstance targetInstance = Playerlist[0];
    foreach (var player in Playerlist)
    {
        float D = Vector3.Distance(transform.position, player.transform.position);
        if (D < Vector3.Distance(transform.position, targetInstance.transform.position))
        {
            targetInstance = player;
        }
    }
    TargetPlayerInstance = targetInstance;
}
```

### 性能/设计问题 (低优先级)

#### 问题 8: NormalMonster.cs 每帧获取玩家列表

**文件位置:** `Shared/SceneObject/SceneMonster/NormalMonster.cs` 第 12-20 行

**问题代码:**
```csharp
private void FixedUpdate()
{
    if (IsServer)
    {
        GetPlayerList();  // 每帧都重新获取列表，性能浪费
        // ...
    }
}
```

**修复建议:**
- 改为事件驱动，当玩家加入/离开时更新列表
- 或使用定时器每隔几帧更新一次

```csharp
private int updateInterval = 10;  // 每 10 帧更新一次
private int frameCount = 0;

private void FixedUpdate()
{
    if (IsServer)
    {
        frameCount++;
        if (frameCount >= updateInterval)
        {
            frameCount = 0;
            GetPlayerList();
        }
        
        if (Playerlist.Count > 0)
        {
            FindPlayerMinDistance();
            MoveToTarget();
        }
    }
}
```
