### 高优先级修复

#### 1. HPBase.cs 伤害计算逻辑错误

**文件位置:** `Server/conmon/HP/HPBase.cs`

**问题描述:**
- 当 `CurrentHealth < damage` 时，没有正确扣减血量，直接触发死亡
- `IsDead` 事件没有订阅者时会抛出 `NullReferenceException`

**修复前:**
```csharp
public void TakeDamage(float damage)
{
    if(CurrentHealth>=damage) CurrentHealth-= damage;
    else IsDead.Invoke();
}
```

**修复后:**
```csharp
public void TakeDamage(float damage)
{
    CurrentHealth -= damage;
    if (CurrentHealth <= 0)
    {
        CurrentHealth = 0;
        IsDead?.Invoke();
    }
}
```

**修复效果:**
- 正确扣减血量
- 使用空条件运算符 `?.` 避免空引用异常
- 血量不会出现负值

#### 2. PlayerInstance.cs OnDisable 字典访问异常

**文件位置:** `Server/Player/PlayerInstance.cs`

**问题描述:**
- 直接使用索引器访问字典，如果键不存在会抛出 `KeyNotFoundException`
- `Server.Instance` 可能为 null

**修复前:**
```csharp
private void OnDisable()
{
    UserPositionAndStatusPacket userStatusPacket = Server.Instance.serverAllPlayerManager.AllPlayerInstancesUserPositionPackets[PlayerIp];
    Server.Instance.serverAllPlayerManager.AllPlayerInstance.Remove(PlayerIp);
    Server.Instance.serverAllPlayerManager.AllPlayerInstancesUserPositionPackets.Remove(PlayerIp);
    userStatusPacket.isDead = true;
    Server.Instance.serviceUpdate.SendToAllPlayerDestoryOBJ(PacketType.PositionAndStatus,userStatusPacket);
}
```

**修复后:**
```csharp
private void OnDisable()
{
    if (Server.Instance?.serverAllPlayerManager == null) return;
    
    var manager = Server.Instance.serverAllPlayerManager;
    
    if (manager.AllPlayerInstancesUserPositionPackets.TryGetValue(PlayerIp, out var userStatusPacket))
    {
        manager.AllPlayerInstance.Remove(PlayerIp);
        manager.AllPlayerInstancesUserPositionPackets.Remove(PlayerIp);
        userStatusPacket.isDead = true;
        Server.Instance.serviceUpdate.SendToAllPlayerDestoryOBJ(PacketType.PositionAndStatus, userStatusPacket);
    }
}
```

**修复效果:**
- 使用 `TryGetValue` 安全访问字典
- 添加空引用检查
- 避免游戏崩溃

        }
    }
}

### 低优先级修复

#### 8. NormalMonster.cs 性能优化

**文件位置:** `Shared/SceneObject/SceneMonster/NormalMonster.cs`

**问题描述:**
- 每帧都调用 `GetPlayerList()`，造成性能浪费

**修复前:**
```csharp
private void FixedUpdate()
{
    if (IsServer)
    {
        GetPlayerList();
        if (Playerlist.Count > 0)
        {
            FindPlayerMinDistance();
            MoveToTarget();            
        }
    }
}
```

**修复后:**
```csharp
private int updateInterval = 10;
private int frameCount = 0;

private void FixedUpdate()
{
    if (IsServer)
    {
        frameCount++;
        if (frameCount >= updateInterval)
        {
            frameCount = 0;
            GetPlayerList();
        }
        
        if (Playerlist.Count > 0)
        {
            FindPlayerMinDistance();
            MoveToTarget();            
        }
    }
}
```

**修复效果:**
- 每 10 帧更新一次玩家列表
- 减少 90% 的列表更新开销
